# Аудит безопасности — 2026-09-04

Исходная ревизия: `558efee`. Проверка текущего исходного кода Go, браузерной части, MCP и конфигурации развёртывания. Код приложения не изменяется; единственный изменяемый файл — этот отчёт. На production запросы не отправляются, торговые операции не выполняются. Каждая подтверждённая находка записывается отдельно по мере проверки и коммитится без push.

Статус: аудит продолжается. P1 — высокий приоритет, P2 — средний; уверенность отражает доказательства в коде, а не факт эксплуатации на сервере.

Агенты: `/root/http_security` — HTTP/авторизация, running; `/root/browser_security` — браузер/вывод данных, running; `/root/integration_security` — интеграции/MCP, running. Все Luna medium, только чтение. Основной агент проверяет развёртывание, хранение секретов и подтверждает результаты.

## SEC-01 — P2: резервный архив с брокерскими токенами доступен другим локальным пользователям при обычном umask

- **Уверенность:** высокая; права production не проверялись, условие эксплуатации указано явно.
- **Доказательства:** `backup-from-server.sh:12,17-23,32,38-41` создаёт каталоги и общий `/tmp/stonks-backup.tar.gz` без `umask 077`, приватного временного каталога или `chmod 600`. В архив копируется вся БД. `go/internal/store/robinhood.go:48-58` сохраняет в ней access/refresh tokens — ключи доступа и продления доступа к брокеру.
- **Сценарий:** при umask `022` архив создаётся с правами `0644`; другой пользователь сервера может скопировать его из `/tmp` до удаления. При ошибке скачивания `set -e` завершает скрипт до очистки. Локальная копия также зависит от прав родительского каталога и umask.
- **Влияние:** раскрытие брокерских токенов и торговых данных локальному пользователю хоста. Доступ из интернета не доказан.
- **Проверка:** в отдельном временном каталоге создан архив только с синтетическим текстом командой `umask 022; tar -czf ...`; измеренные права — `0644`. Реальные данные и сервер не использовались; временные файлы удалены.
- **Минимальное исправление (не выполнено):** `umask 077` на обеих сторонах, `mktemp -d` для удалённой подготовки, `trap` для очистки; архив и локальный каталог должны быть доступны только владельцу.
- **Критерий приёмки:** при исходном umask `022` второй локальный пользователь не может прочитать архив; искусственный сбой передачи удаляет удалённые временные файлы.

## SEC-02 — P2: неавторизованный клиент может неограниченно увеличивать HTTP-журнал даже после ответа 429

- **Уверенность:** высокая; поведение воспроизведено локально без сетевого сервера.
- **Доказательства:** `go/internal/httpapi/server.go:106-107` ставит accessLog снаружи ограничения частоты запросов. `go/internal/httpapi/accesslog.go:67-94,129-143` записывает каждый `/api/` запрос, включая отклонённые, и сохраняет всю строку параметров URL без ограничения длины. `accesslog.go:204-245` меняет имя файла только раз в месяц, пишет через append и не ограничивает размер/срок хранения. `docker-compose.yml:22,26-29` включает этот журнал в постоянном Docker-томе без квоты в конфигурации проекта.
- **Сценарий:** без входа в аккаунт отправлять запросы с большим обычным query-параметром. Даже после исчерпания лимита и получения `429 Too Many Requests` каждый запрос продолжает увеличивать файл. Например, параметр длиной 64 KiB не блокируется ограничением тела запроса Caddy.
- **Влияние:** заполнение диска и отказ записи состояния/БД при общем файловом разделе. Реальные квоты, внешняя очистка и свободное место production не проверялись; полный диск намеренно не воспроизводился.
- **Проверка:** временный Go overlay — подмена тестового файла только для запуска компилятора, без изменения репозитория — исчерпал корзину одного тестового IP и отправил два синтетических запроса через `httptest`. Оба получили 429, но добавили **131 376 байт** в журнал. Тест `TestSecurityAuditRejectedRequestLogGrowth` прошёл.
- **Минимальное исправление (не выполнено):** ограничить длину сохраняемых query/полей, ограничить журналирование повторных отказов и настроить ротацию по размеру с удалением старых файлов или квоту.
- **Критерий приёмки:** повторные отклонённые запросы не дают неограниченного роста; размер и число файлов ограничены проверяемыми пределами.
