## Зачем

Полный повторный аудит на ТЕКУЩЕМ HEAD, а не пересказ старых документов.
Зелёные тесты, закрытый пункт roadmap и статус FIXED_UNVERIFIED не значат
«баг исчез». Ищи то, что тесты и `-race` не ловят: fail-open, гонки
check-then-act, расхождение live/бэктест/SPA, порча денег и состояния.

Не объявляй проект чистым, потому что аудит закончился.

## Инварианты, которые обязан проверить кодом

### Live / autotrade / IBS

- Сделки только на официальном закрытии сессии.
- T-11: обзор IBS, ордеров нет.
- T-1: решения и ордера по IBS, снятым в T-1, не по превью T-11.
- Вход: минимальный IBS, строго `ibs < lowIBS`. Ровно 0.10 — не вход.
- Выход: строго `ibs > highIBS`. Повторный вход в тот же день — только после
  полного закрытия.
- Live ходит через `ibs.IsEntrySignal` / `ibs.IsExitSignal` в `go/internal/ibs`.
  Порог до предиката не подменяется (`0` ≠ «не задано» → 0.10).

### Store / состояние

- Ошибка чтения pending-трекера, позиции, настроек, журнала, календаря,
  watchlist — fail-closed.
- Check-then-act — одна транзакция / условный `UPDATE` + `RowsAffected`.
- Идентификатор заявки или устойчивый журнал намерения до отправки.

### HTTP API

- Пустой `ADMIN_PASSWORD` — fail-closed 503.
- Нет `ok: true` после ошибки записи.
- PATCH не затирает чужие ключи отсутствующими полями.

### SPA

- Торговая дата — строка `YYYY-MM-DD`. Запрещены `new Date(d)`, `Date.parse`,
  `toISOString`, `toLocaleDateString`, локальные `getFullYear`/`getMonth`/`getDate`
  на торговой дате.
- UI не дублирует IBS/CAGR/календарь вразрез с Go.

### Backtest

- Комиссия, CAGR, сплиты, IBS-пороги — один источник истины между движками
  и SPA.
- Плечо/маржин-колл как в `CLAUDE.md` / `SimulateMargin`.

### Scheduler

- T-11/T-1 не пропускаются из-за задержанного тика.
- Задача не «выполнена» до успешной отправки.
- Отказ чтения календаря ≠ пустой календарь.

### Brokers

- Брокер не теряется и не подменяется default-брокером в исполнении, трекере,
  ручном закрытии, журнале, сверке.
- Истечение токена не выдаётся за «истекает скоро» или за истекшую сессию сайта.
- Живые ордера не размещать.

### Dates

- Торговая дата — строка `YYYY-MM-DD`, без времени и таймзон.
- Операции через `go/internal/tradingdate`.
- Wall-clock только `America/New_York`. «Какой торговый день» — `TodayNYSE`.
- Невозможный день отвергается.
- Проверка: `TZ=Pacific/Auckland` и `TZ=America/Los_Angeles` — разница = баг.

## Подсистемы (у каждой явный вердикт)

1. Пороги IBS и паритет live ↔ бэктест ↔ SPA
2. Live-движок: monitor, autotrade, sizing, safety
3. Трекеры заявок, журнал, идемпотентность
4. Брокеры: Webull и Robinhood
5. Планировщик T-11 / T-1 / after-close
6. Telegram-транспорт мониторинга
7. HTTP API, auth, calc, live handlers
8. Vanilla SPA
9. Store / SQLite
10. Даты и календарь NYSE
11. Бэктест, метрики, плечо, опционы, сплиты
12. Провайдеры OHLC
13. Эксплуатация, деплой, контейнеры, секреты
14. MCP YouTube
15. Наблюдаемость и ложные статусы

Шкала: **P0** деньги/порча данных/секрет, **P1** неверное штатное поведение,
**P2** хрупкость, **P3** мелочь.

Каждая находка: что → где (file:line) → почему баг → как проверить.
Подозрение без доказательства — в раздел «не доказано».
