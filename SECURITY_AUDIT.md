## SEC-01 — P2: резервный архив с брокерскими токенами доступен другим локальным пользователям при обычном umask

- **Уверенность:** высокая; права production не проверялись, условие эксплуатации указано явно.
- **Доказательства:** `backup-from-server.sh:12,17-23,32,38-41` создаёт каталоги и общий `/tmp/stonks-backup.tar.gz` без `umask 077`, приватного временного каталога или `chmod 600`. В архив копируется вся БД. `go/internal/store/robinhood.go:48-58` сохраняет в ней access/refresh tokens — ключи доступа и продления доступа к брокеру.
- **Сценарий:** при umask `022` архив создаётся с правами `0644`; другой пользователь сервера может скопировать его из `/tmp` до удаления. При ошибке скачивания `set -e` завершает скрипт до очистки. Локальная копия также зависит от прав родительского каталога и umask.
- **Влияние:** раскрытие брокерских токенов и торговых данных локальному пользователю хоста. Доступ из интернета не доказан.
- **Проверка:** в отдельном временном каталоге создан архив только с синтетическим текстом командой `umask 022; tar -czf ...`; измеренные права — `0644`. Реальные данные и сервер не использовались; временные файлы удалены.
- **Минимальное исправление (не выполнено):** `umask 077` на обеих сторонах, `mktemp -d` для удалённой подготовки, `trap` для очистки; архив и локальный каталог должны быть доступны только владельцу.
- **Критерий приёмки:** при исходном umask `022` второй локальный пользователь не может прочитать архив; искусственный сбой передачи удаляет удалённые временные файлы.
