# Аудит: /stocks, /ema, /multi-ticker-options (React → Go SPA)

Область: MultiTickerPage / EmaStrategyPage / MultiTickerOptionsPage / BacktestResultsView и
вложенные компоненты (React) vs go/web/js/app.js + charts.js (Go).

Методологическая заметка: `src/components/SingleTickerPage.tsx` (маршрут `/results`) в
текущем React-приложении **не роутится** — `AppRouter.tsx:435` делает
`<Route path="/results" element={<Navigate to="/stocks" replace />} />`. Реальный компонент,
обслуживающий как один, так и несколько тикеров на `/stocks` — это `MultiTickerPage.tsx`
(режим `isSingleTicker` внутри него). Поэтому находки ниже сравнивают Go `pageStocks()` именно
с `MultiTickerPage.tsx`, а не с мёртвым `SingleTickerPage.tsx`. Особенности `SingleTickerPage.tsx`
(симуляция Maintenance Margin/ликвидации, кнопка "В мониторинг", попап с `updatedAt`) в находки
не включены, т.к. пользователи их и в React не видят.

Каждая находка ниже описывает, как правило, не один, а несколько конкретных потерянных элементов
UI (переключатели, графики, таблицы, метрики) — фактическое число отдельных регрессий существенно
